# 湖心亭看雪

七幅 AI 画作，配《湖心亭看雪》完整正文：西湖大景、毳衣炉火、一痕一点一芥、亭中相逢、炉火近景、饮酒、张岱追忆写作的心境。

浏览器直接打开 `index.html`。画作已内嵌，约 2.7 MB，不需要安装依赖或联网。页面只呈现画面与正文。

滚动时，画面停驻并缓慢推近，正文逐段浮现，七幅画以细长的雪雾纹理溶解衔接；向上滚动可回看。桌面端有轻微的鼠标视差。

参考提供的 Moonshot 录屏，将图像的细微扰动与短促淡入用于雪夜：湖水有轻波，细雪缓缓掠过，炉火与孤灯微微明灭。画作保持原有构图，文字停稳后不随纹理晃动。

点击亭中的炉火走近，再点击近景中的火堆进入饮酒，点击举起的酒杯进入追忆。每次点击都从火光或杯盏拉入下一幅画；键盘 Tab、Enter 可操作，Escape 可取消过渡，浏览器返回可回到上一处。

遵循系统的“减少动态效果”设置，短屏与关闭 JavaScript 时采用连续的静态阅读；打印保留完整正文。纹理动效使用原生 WebGL，限制绘制帧率与分辨率，后台标签页暂停；不支持 WebGL 或图形上下文丢失时恢复原图与淡化过渡。无外部脚本、字体或图片请求。

文字出自张岱《陶庵梦忆·湖心亭看雪》。图像为文学意象创作，最后一幅以晚年追忆为想象，并非历史现场或真实肖像。
