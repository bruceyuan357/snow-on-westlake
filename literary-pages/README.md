# 岳阳楼记与醉翁亭记

两篇分别采用完整正文和十二幅 AI 画作，不添加额外的可见介绍、导航或解释。图像是文学意境创作，人物并非真实肖像，建筑和景物也非历史现场的精确复原。《岳阳楼记》结尾以范仲淹在邓州遥思天下为想象，《醉翁亭记》结尾表现欧阳修与民同乐、醒而述文的心境。

滚动推进画面与正文，向上可回看。画中的泉水、灯火、酒杯和案卷有轻微的光圈提示，点击会从该处拉入下一幅近景；键盘 Tab、Enter 可操作，Escape 可取消过渡，浏览器返回可回到上一处。两篇的雨、水纹、林间微尘与灯火动效按各自场景设置。

`../yueyang-lou-ji/index.html` 和 `../zuiweng-ting-ji/index.html` 是独立可部署的网页。所有图像、样式与脚本均内嵌，无外部依赖或网络请求。分别将所需的 `index.html` 放进网站根目录即可，也可把两个目录原样放到同一网站的不同路径。

维护源文件为 `content.cjs`、两篇原文 `.txt`、`styles.css`、`motion.js`、`paintings.js` 与 `art/*.webp`。安装了 Node.js 后，在仓库根目录运行：

```sh
node literary-pages/build.cjs
```

构建不需要安装任何 npm 包，会先校验每个分镜拼接后是否与完整原文一致。画作原始 PNG 保留在生成工作区，部署使用压缩后的 WebP。

运行 `python3 literary-pages/package.py` 会在仓库的上一级目录生成 `yueyang-lou-ji.zip` 和 `zuiweng-ting-ji.zip`。每个 ZIP 的根目录只有 `index.html`，并校验文件完整性及小于 32 MB 的限制。

遵循“减少动态效果”偏好；短屏、禁用 JavaScript 时保留完整静态阅读；打印只输出正文。后台标签页暂停绘制；WebGL 不可用或上下文丢失时回退到原图，仍可滚动与点击。长篇阅读最多缓存四幅 GPU 纹理，并根据绘制速度降低特效分辨率。
